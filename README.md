Objective
To build a Simple Linear Regression model to predict house prices based on median income.

Dataset
- Name:California Housing Dataset
- Source: [Scikit-learn California Housing Dataset](https://scikit-learn.org/stable/datasets/real_world.html)

Work Done
- Loaded and explored the dataset.
- Selected Median Income as the input feature.
- Selected Median House Value as the target.
- Visualised the relationship using a scatter plot.
- Split the data into 80% training and 20% testing.
- Trained a Linear Regression model.
- Evaluated the model using MAE, MSE and R² score.
- Compared actual and predicted house prices.
- Predicted the price for a new example.

Tools Used
Python, Google Colab, Pandas, NumPy, Matplotlib and Scikit-learn.

Conclusion
A Simple Linear Regression model was successfully developed to predict house values based on median income.
